## 📖 Sobre o projeto

**Around the U.S.** é uma aplicação web desenvolvida em **React** como parte da formação em Desenvolvimento Web da TripleTen.

O projeto simula uma rede social para compartilhamento de fotos, permitindo visualizar cartões, editar informações do perfil e interagir com a interface através de popups reutilizáveis.

Durante o desenvolvimento foram aplicados conceitos fundamentais do React, componentização, gerenciamento de estado, manipulação de eventos e organização de código em uma arquitetura escalável.

---

## ✨ Funcionalidades

- Perfil do usuário
- Edição das informações do perfil

- Listagem dinâmica de cartões
- Visualização ampliada das imagens
- Curtir cartões

## 🚀 Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/gustavoagsilva/web_project_around_react.git
```

Entre na pasta:

```bash
cd web_project_around_react
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

O projeto estará disponível em:

```text
http://localhost:5173
```
